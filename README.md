# Replication Project

Organized workspace for the replication project.

## Structure

- `code/` — scripts and other analysis code
- `data/raw/` — original, unmodified data
- `data/clean/` — cleaned and analysis-ready data
- `results/figures/` — figures generated by the analysis
- `results/tables/` — tables generated by the analysis

Keep raw data unchanged; save processed data in `data/clean/` and generated outputs in `results/`.
